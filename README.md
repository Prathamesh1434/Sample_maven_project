# Hello World Maven Project

This is a simple Java "Hello World" project built with Maven.

## Prerequisites

- Java 8 or higher
- Apache Maven

## How to Build

To build the project and create a runnable JAR file, run the following command from the project root:

```bash
mvn package
```

This will create a JAR file in the `target` directory named `hello-world-1.0-SNAPSHOT.jar`.

## How to Run

To run the application, use the following command:

```bash
java -jar target/hello-world-1.0-SNAPSHOT.jar
```

You should see the output "Hello, World!" in your console.
